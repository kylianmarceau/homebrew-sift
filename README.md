# Homebrew tap for Sift

[Sift](https://github.com/kylianmarceau/sift) is a fast keyboard launcher
for macOS (Apple Silicon, macOS 13 or later).

```bash
brew install --cask kylianmarceau/sift/sift
```

Update with `brew upgrade`. Uninstall with `brew uninstall --cask sift`,
or `brew uninstall --zap --cask sift` to also remove Sift's data
(`~/.config/sift` is kept).

The cask is updated by Sift's release process; see
[RELEASING.md](https://github.com/kylianmarceau/sift/blob/main/RELEASING.md).
